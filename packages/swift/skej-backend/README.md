This package embeds the scheduling core from [Skej Development](https://github.com/CountableNewt/skej-at/tree/40d336daee8041e01d883b3ae6ca3479f12ea340/packages/skej-kit) in The Social Wire's AppView. It preserves the `at.skej.schedule` records, calendar projection, canonical post and article publishing, and SQLite queue. AppView supplies authenticated actor identities and a transport that pins public IP addresses. A separate Social Wire OAuth client holds the grants used to publish while the user is offline.

After account authorization, the enabled legacy import reads that account's PDS records and preserves their schedule and publication record keys. Enable import only after stopping the standalone worker. Previously attempted schedules whose publication may be incomplete remain visible with a review message and require manual reconciliation. A process interruption during an embedded publish can also leave the active job in Publishing for review. The worker claims one job at a time so an interruption cannot strand a batch of unstarted jobs.

The worker preserves stored embeds and can hydrate a missing thumbnail through AppView’s pinned HTTPS transport. Unsupported or unavailable previews remain publishable.
